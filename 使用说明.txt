WorkBuddy 状态面板  v0.6.5
========================================

桌面角落的悬浮小窗口：不用切窗口，随时看 WorkBuddy 的思考过程、
执行步骤、点数消耗，遇到需要确认的操作会自动响铃弹窗提醒。
默认纯本地运行，不联网、不上传数据（积分功能需手动开启，见第六节）。

适用系统：Windows 10 / 11（64 位），且已安装并登录 WorkBuddy 桌面版。


一、怎么开始用（3 步）
----------------------------------------
1. 解压到任意文件夹（不要放 C 盘根目录），双击「WorkBuddy面板.exe」。
   （首次运行如果 Windows 弹出保护提示，点「更多信息 -> 仍要运行」）
2. 第一次打开会自动对接 WorkBuddy，并弹出气泡提醒。
3. 按提醒【完全退出并重开一次 WorkBuddy】，之后开任意任务就能看到内容。


二、常用操作
----------------------------------------
Ctrl + Alt + W     随时显示 / 隐藏面板（可在设置里改键）
拖动顶部栏         移动窗口位置（会自动记住）
点右上角 —         折叠成一行；再点一次展开，并回到屏幕右下角
点右上角 ×         收进右下角托盘，程序继续在后台运行
右键托盘图标       显示/隐藏、总在最前、设置、修复连接、退出
点右上角齿轮       改显示内容、拦截模式、快捷键或清空记录

注意：点 × 是收进托盘（继续帮你盯进度、拦危险操作）；
     点托盘右键「退出…」才是彻底关掉面板。


三、窗口高度
----------------------------------------
默认是自适应：你在设置里勾了哪几个区块，窗口就有多高，不会留半屏空白。
如果你手动拖过一次窗口边框，面板就把高度交给你，内容再变也不动它。
想交还给自适应：设置 -> 窗口 -> 「恢复自适应高度」。

折叠和展开不会改变窗口位置：折叠时从底边往上收，展开时先吸回
屏幕右下角再按内容高度重新量一次。拖到屏幕中间折叠也一样。


四、右下角的连接灯
----------------------------------------
绿「已连接」  面板和本地服务正常，思考和步骤实时刷新
黄「重连中」  连接断了一下，正在自动重试（几秒内恢复就看不出来）
红「已断开」  重连多次仍失败，面板停在上一次的数据上

圆点后面就是当前状态名，不用把鼠标移上去猜。颜色只是第二重提示。


五、状态灯颜色（左上角）
----------------------------------------
灰        空闲
黄        正在思考 / 执行中
绿        这一轮完成了
红        出错了
橙（闪）  WorkBuddy 弹了权限窗，需要你去点允许或拒绝
橙（不闪）它答完了，最后一句在问你问题，去回它就行


六、积分区块（需联网，默认关闭）
----------------------------------------
指标下面单独一块，写「剩余总点数」和「每日积分」。

【默认关闭】不做任何操作时，面板不联网、也不读你的登录凭据，
那一块显示「未开启」。

想用的话：点齿轮 -> 「积分（需联网）」-> 勾上「查询积分余额与签到状态」。
勾上后它只做两件事：查余额、查今天领没领，都是直连 WorkBuddy 官方接口。

再勾「每天自动领取 100 积分」，面板会在每天你打开电脑后的第一次检查里
顺手把当日积分领掉（当天已领就不会重复发请求，接口本身也是幂等的）。

界面上的四种样子：
「剩余总点数 3,262」+「● 已领取 +100」   正常，数据是新的
「…」                                    正在查（第一次会慢一两秒）
「—」+ 右上角「未连接」                    拿不到数据（比如客户端没登录）
「—」+ 右上角「未开启」                    你还没开这个开关

几个细节：
- 余额显示取整（3,262），鼠标停上去能看到精确到分的值。
- 右上角的「刷新」可以立刻重查一次，不用等 30 分钟。
- 显示「○ 未领取」时，点那一格就能立刻补领。
- 数据每 30 分钟更新一次，跨过零点会自动再查一次。
- 拿不到数据时显示「未连接」，绝不会假装成「今天还没领」。
  那一行下面会直接写出原因，照着处理即可：
    未找到客户端程序    -> 确认 WorkBuddy 已正常安装（不必正在运行）
    客户端未登录        -> 打开 WorkBuddy 登录一次，再点「刷新」
    登录已过期          -> 同上，令牌失效了
    凭据文件被占用      -> 等几秒再点「刷新」，客户端正写这个文件
    请求超时或网络不通  -> 检查网络和代理
- 关于凭据：解出来的令牌只存在内存里，用完即弃，不落盘、不进日志、
  不会传给界面。介意的话就别开这个开关，其他功能完全不受影响。

不想看这一块：设置 -> 显示区块 -> 取消勾选「积分」。


七、出问题了看日志
----------------------------------------
程序文件夹里会有一个 logs 文件夹（首次运行后自动生成）：
  logs\hud.log        外壳日志：版本、显示器缩放、窗口尺寸变化、后端端口
  logs\service.log    后端日志：凭据读取、客户端定位、解密耗时、接口状态码

设置 -> 「诊断日志」可以直接看到位置和体积，也能一键打开文件夹或清空。
遇到问题把这两份文件一起发出来，基本就能定位。

日志里不含令牌、凭据内容和请求头，但会写本机路径和用户名，
所以适合发给开发者排查，不适合公开发到论坛。
单个文件超过 2 MB 会自动滚动，最多占 8 MB，不会越攒越大。

如果程序放在 C:\Program Files 这类没有写权限的位置，
日志会改写到 %LOCALAPPDATA%\workbuddy-hud\logs —— 设置里显示的就是真实路径。


八、怎么彻底卸载
----------------------------------------
不要直接删文件夹！按下面 3 步来：
1. 双击本文件夹里的「卸载.bat」，输入 Y 回车。
2. 完全退出并重开一次 WorkBuddy。
3. 删除整个程序文件夹即可（logs 文件夹会跟着一起删掉）。


九、常见问题
----------------------------------------
1. 面板一直空的：右键托盘图标点「修复与 WorkBuddy 的连接」，然后重开 WorkBuddy。
2. 双击没反应：系统缺少 WebView2（Win11 自带，Win10 去微软官网装一下即可）。
3. 快捷键没反应：可能和别的软件冲突，点齿轮进设置换一个组合键。
4. 窗口高度不跟着内容变：你拖过一次边框，属于手动高度；
   设置 -> 窗口 -> 「恢复自适应高度」即可。
5. 换了高分辨率或缩放 125% / 150% 的显示器后窗口下方有空白：
   0.6.4 及更早版本的问题，0.6.5 已修正；确认版本号，或在设置里
   点一次「恢复自适应高度」。
